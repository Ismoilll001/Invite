BAZMNOMA — ОБНОВЛЕНИЕ РАБОЧЕЙ ПАПКИ
Версия: 19 ноября 2026 года.

1. Распакуйте архив. Внутри находится папка BAZMNOMA.
2. Сделайте резервную копию вашей нынешней рабочей папки Invite.
3. Скопируйте ВСЁ СОДЕРЖИМОЕ папки BAZMNOMA в рабочую папку Invite
   (GitHub Desktop → Repository → Show in Explorer), подтвердите замену файлов.
   Не переносите саму папку BAZMNOMA как вложенную папку.
   Не удаляйте существующую папку .git и ваши локальные файлы .dev.vars/.env.
4. В GitHub Desktop просмотрите изменения. Когда готовы обновить рабочий сайт,
   укажите описание, например «Update BAZMNOMA», нажмите Commit, затем Push origin.
   При включённой связи с GitHub Cloudflare автоматически запустит сборку.
5. В Cloudflare проверьте завершение Deployments и откройте сайт.

НАСТРОЙКИ CLOUDFLARE (сохраняются существующие)
Worker: invite
Build command: npm run build
Deploy command: npx wrangler deploy --config dist/server/wrangler.json
Root directory: /
D1 binding: DB → khushbakht-db
R2 binding: BUCKET → khushbakht-files
ADMIN_PASSWORD: существующий секрет Cloudflare, не переносится в архиве.

ЛОКАЛЬНЫЙ ЗАПУСК
Node.js 22.13 или новее.
В папке проекта: npm ci
Для проверки сборки: npm run build
Для разработки: npm run dev

ЧТО ВНУТРИ
Полный исходный код, изображения, локальные шрифты, музыка, миграции,
настройки Cloudflare и уведомление об использованном стороннем шаблоне.
Название BAZMNOMA; два активных шаблона; новый кадр телефона и фотобаннер;
исправленная заставка ворот; оригинальная музыка полумесяца;
три бабочки формы №2, полёт замедлен вдвое;
падающие и парящие точки.

Архив содержит исходники, а не копию данных Cloudflare.
Существующие заказы и файлы клиентов остаются в D1 и R2.
Новые таблицы для этого визуального обновления создавать не нужно.
Не запускайте повторное создание базы или очистку таблиц.
Старые шаблоны сохранены в коде для совместимости с уже созданными заказами,
но убраны из каталога.

Уже существующие команды сборки из предыдущей настройки тоже подходят:
npx vite build --config vite.cloudflare.config.ts
npx wrangler deploy --config dist/server/wrangler.json
