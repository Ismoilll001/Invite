BAZMNOMA — РАБОЧАЯ ПАПКА
Версия: 20 ноября 2026 года.

ПЕРЕНОС ФАЙЛОВ
1. Сделайте резервную копию своей рабочей папки Invite.
2. Распакуйте ZIP. Откройте папку BAZMNOMA.
3. Скопируйте ВСЁ СОДЕРЖИМОЕ BAZMNOMA в свою рабочую папку Invite,
   подтвердив замену. Не вкладывайте саму папку BAZMNOMA внутрь Invite.
   Рабочая папка: GitHub Desktop → Repository → Show in Explorer.
   Сохраните свою папку .git и локальные .dev.vars/.env. Их в ZIP нет.
4. Перед публикацией примените недостающие миграции базы (ниже).
5. В GitHub Desktop сделайте Commit и Push origin.
6. Дождитесь успешного Deployment в Cloudflare и проверьте сайт.

БАЗА ДАННЫХ — ПЕРЕД ПУБЛИКАЦИЕЙ
Существующие базу и таблицы НЕ удаляйте и НЕ создавайте заново.
Заказы, фотографии и квитанции остаются в существующих D1 и R2.

Если миграция RSVP 0002 ещё НЕ выполнялась, ОДИН РАЗ:
  npx wrangler d1 execute DB --remote --config wrangler.jsonc --file drizzle/0002_famous_madame_masque.sql

Если миграция для именных ссылок и пожеланий 0003 ещё НЕ выполнялась,
ОДИН РАЗ:
  npx wrangler d1 execute DB --remote --config wrangler.jsonc --file drizzle/0003_workable_quicksilver.sql

Уже выполненные миграции не повторяйте. Таблицы 0002:
invitation_rsvps, rsvp_limits. Таблицы 0003:
invitation_guests, invitation_wishes.
Если не уверены, сначала проверьте таблицы своей D1.
Команды выполняются из рабочей папки, после npm ci и входа в Cloudflare.

СОХРАНЁННЫЕ НАСТРОЙКИ CLOUDFLARE
Worker: invite
Build command: npm run build
Deploy command: npx wrangler deploy --config dist/server/wrangler.json
Root directory: /
D1: DB → khushbakht-db
R2: BUCKET → khushbakht-files
ADMIN_PASSWORD: существующий секрет Cloudflare, в ZIP не включён.

ЛОКАЛЬНЫЙ ЗАПУСК
Node.js 22.13 или новее.
Установка: npm ci
Разработка: npm run dev
Сборка: npm run build
